# СМИТАП – концепты первого экрана главной

Два интерактивных концепта первого экрана для онлайн-школы подготовки к ЕГЭ и ОГЭ СМИТАП.

- **Версия 2** – маскот на сцене с объемными буквами: [`v2/`](v2/)
- **Версия 3** – интерфейс платформы в 3D, тетрис-сборка, змейка-стрелка: [`v3/`](v3/)

Опубликовано через GitHub Pages – ссылки в описании репозитория.

## Как развернуть у себя

Это статичные страницы: HTML, CSS и JS без сборки и зависимостей.

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/timofeevaekaterinan-rgb/smitup-concepts.git
   cd smitup-concepts
   ```
2. Запустить любой локальный сервер из корня репозитория, например:
   ```bash
   python3 -m http.server 8000
   ```
   или `npx serve .`
3. Открыть `http://localhost:8000/v2/` или `http://localhost:8000/v3/`.

Открывать `index.html` двойным кликом (через `file://`) не стоит: браузер не даст загрузить шрифты и картинки сцены.

## Структура

```
index.html          – стартовая страница со ссылками на обе версии
v2/index.html       – версия 2
v3/index.html       – версия 3 (векторы макета платформы встроены прямо в HTML)
assets/fonts/       – шрифт Visuelt (Regular, Medium, Black)
assets/logo-dark.svg
assets/scene/       – фон, буквы и реквизит сцены v2, лента и наконечник стрелки v3
```

## Параметры для проверки

К адресу можно добавить параметры:

- `?shot` – статичный кадр без анимаций (для скриншотов);
- v2: `?shot&p=0.8` – положение скролла от 0 до 1, `&mode=plat&f=0..5` – сразу сцена с платформой, `&emo=anger` – любая эмоция маскота из брендбука;
- v3: `?shot&stop=intro` – кадр с большим заголовком, `&route=lr&sp=0.4` – фиксированный маршрут змейки, `&wemo=joy` – эмоция маскота в углу.
